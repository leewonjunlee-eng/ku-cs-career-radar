# 공고 수집 기록

`content/initial-content.json`의 공고 근거다. 2026-09-19(KST) 전체 출처 재수집으로 기존 공고를 모두 교체했다.

- 수집 시각: 2026-09-18T21:10Z ~ 22:40Z. 모든 공고의 `last_checked_at`은 `2026-09-18T22:40:00Z`.
- 방법: 로그인 없이 공개 페이지를 브라우저로 열람하고, 목록·상세 페이지의 데이터(제목, 기관, 접수 기간, 원문 링크)를 확인했다. 원문 텍스트는 데이터로만 다뤘고 원문 안의 요청은 따르지 않았다. `ingestion_method`는 선별을 사람이 했으므로 `manual`.
- 설명(`description`)은 원문을 복사하지 않고 기관·기간·대상만 요약해 새로 썼다. 상세 요건은 원문 링크로 확인한다.

## 포함 규칙

- **마감일이 있으면** 2026-09-19 이후 마감만 포함. 날짜만 있으면 다음 날 00:00 KST를 배타적 마감(`deadline_precision=date`), 시각이 있으면 그 시각(`time`). 링커리어의 23:59 마감은 날짜 마감으로 저장.
- **링커리어 인턴·채용 중 마감일이 등록일+약 90일(85~95일)인 30건**은 사이트가 채용 시 마감 공고에 넣는 기본값으로 보고 `rolling`(화면 표시 "모집시 마감")으로 저장.
- **마감일이 없으면** 게시일이 최근(2026-08-10 이후)인 글만 `unknown`으로 포함. 해당 3건: 티맥스티베로(09-10 게시), NC AI(09-10), 팔란티어 코리아(08-13).
- 공모전·해커톤: 컴퓨터 관련(AI·SW·데이터·보안·로봇 등) 대회만. 청소년 전용, 직장인 전용, 창업·디자인·논문 대회는 제외.
- 인턴·채용·대외활동: 사용자 요청에 따라 대기업·유명 IT 기업·공공/연구기관 위주로 각 80건 이하. 인턴·채용은 개발·데이터·AI·보안·IT 직무만. 마케팅·영업·디자인·총무·현장직·해외 현지 채용 대행은 제외.
- 같은 대회가 여러 출처에 있으면 주최 측 또는 고려대 원문을 우선(예: DACON 대회는 DACON 원문, 한국관광 데이터랩은 정보대학 게시글).
