# 연구실 정보 출처

확인일: 2026-09-19  
범위: 고려대학교 서울캠퍼스의 컴퓨터학과·인공지능학과·뇌공학과·정보보호 분야 연구실은 공식 목록 전체를 수록했다. 전기전자공학부·산업경영공학부·바이오의공학부·기계공학부는 공식 목록 중 컴퓨터 과학, 소프트웨어, 인공지능·기계학습, 데이터 분석, 컴퓨터 비전, 로보틱스, HCI, 컴퓨팅 기반 신호처리, 임베디드 시스템, 컴퓨터 구조·시스템, 네트워크·통신 소프트웨어, 의료정보처리·영상재구성을 주된 주제로 명시한 연구실만 수록했다. 단순 반도체·소자·광학·전력·회로·재료, 순수 최적화·생산·공급망, 바이오 소재·진단기기 연구실은 제외했다. 이 디렉터리는 연구실의 연구 분야와 공식 링크를 찾기 위한 자료이며 모집 여부를 나타내지 않는다.
